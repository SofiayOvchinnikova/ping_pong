# Ping Pong 🚀

2D игра — космический пинг-понг, в котором две космические ракетки перекидывают друг другу летающую тарелку.

## Описание

Классический пинг-понг в космическом сеттинге. Вместо привычных платформ игроки управляют космическими ракетками, а вместо мяча по полю летает НЛО (летающая тарелка). Побеждает тот игрок, чью сторону экрана не задела тарелка соперника.

## Управление

| Игрок | Клавиши |
|---|---|
| Левый игрок | `W` — вверх, `S` — вниз |
| Правый игрок | `↑` (стрелка вверх), `↓` (стрелка вниз) |

## Правила

- Если летающая тарелка коснулась **левой** части экрана — побеждает **правый** игрок.
- Если летающая тарелка коснулась **правой** части экрана — побеждает **левый** игрок.
